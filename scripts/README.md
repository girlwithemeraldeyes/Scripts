# Scripts de administración de sistemas

Esta carpeta reúne ejercicios de PowerShell para Windows, scripts Bash para Linux y una guía de comandos de Linux.

## Windows

Los archivos con extensión .ps1 son scripts de PowerShell. Abre PowerShell, sitúate en la carpeta Windows y ejecuta el script con .\nombre-del-script.ps1. El script de búsqueda de archivos pide la ruta que quieres analizar. El script de directorios crea una carpeta Pruebas junto a sí mismo; el de procesos guarda procesos.csv en esta carpeta.

## Linux

Los archivos con extensión .sh son scripts Bash. La guía COMANDOS.md reúne los comandos individuales, que se escriben directamente en la terminal. Para ejecutar un script: dale permiso con chmod +x nombre-del-script.sh y ejecútalo con ./nombre-del-script.sh. El script de servicios desde archivo lee la lista de Linux/datos/servicios.txt, salvo que le pases otra ruta como argumento.
